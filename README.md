# Arithmetic Game

An serverless Zetamac clone (simple mental arithmetic speed drill), with **statistics**, built with vanilla HTML, CSS, and JavaScript.

## How to Run

### Option 1: Browser (Static)
Open `index.html` in your browser, or use the Github Page deploy.

### Option 2: Local Server (Bun)
```bash
bun run dev
```
Open [http://localhost:3000](http://localhost:3000).
